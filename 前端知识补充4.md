**警告你：`setTimeout` 的某一种用法非常危险**。我直接用**最经典、最容易理解的 XSS 例子**给你说明。

------

## 一、危险点先点明（重点）

`setTimeout` **有两种用法**：

### ✅ 安全用法（你现在用的）

```
setTimeout(() => {
  alert("safe");
}, 1000);
```

### ❌ 危险用法（注入入口）

```
setTimeout("alert('XSS')", 1000);
```

⚠️ **只要第一个参数是字符串，它就会被当成 JS 代码执行**
 👉 这就是文档里说的 **“code parameter”**。





The `setTimeout()` function is commonly used to call a function that is executed just **once**, after a delay. You can call clearTimeout  to cancel the timeout before it completes.

If you wish to call a function **repeatedly** , you can use setInterval
